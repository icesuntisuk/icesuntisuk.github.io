สถานการณ์พื้นฐาน (Baseline Scenario)

🏢
สถานการณ์พื้นฐาน (Baseline Scenario)
ข้อมูลองค์กรและสภาพแวดล้อมก่อนเริ่มการฝึก

องค์กรเป็นหน่วยงานรัฐด้านการจัดการทรัพยากรน้ำ มีบทบาทสำคัญในการบริหารจัดการน้ำของประเทศ ระบบสารสนเทศมีความสำคัญต่อการให้บริการประชาชนและการบริหารจัดการทรัพยากรน้ำ

🏭 บริบททางภูมิรัฐศาสตร์ (Geopolitical Context)

ในช่วง 2-3 เดือนที่ผ่านมา ประเทศน้ำเงิน (ฝ่ายเรา) มีข้อพิพาททางภูมิรัฐศาสตร์กับ ประเทศแดง (ฝ่ายตรงข้าม) จากเหตุการณ์พิพาทชายแดนที่ทวีความรุนแรงขึ้น กลุ่มแฮกเกอร์ (hacktivists) และกลุ่ม Nation-State Affiliated จากฝั่งประเทศแดง ได้ทำการโจมตีทางไซเบอร์ต่อหน่วยงานรัฐบาลของประเทศน้ำเงินหลายแห่ง

กลุ่ม "Phantom Tide" — กลุ่มแฮกเกอร์ Nation-State Affiliated ที่เชื่อว่าได้รับการสนับสนุนจากประเทศแดง ได้จ้องโจมตีโครงสร้างพื้นฐานสำคัญทางสารสนเทศ (Critical Information Infrastructure — CII) ของประเทศน้ำเงิน กรมทรัพยากรน้ำซึ่งเป็นหน่วยงาน CII ตามพ.ร.บ.การรักษาความมั่นคงปลอดภัยไซเบอร์ พ.ศ.2562 ตกเป็นเป้าหมายหลักในการโจมตีครั้งนี้

บทบาทผู้เข้าร่วม

👥
บทบาทผู้เข้าร่วมการฝึก
4 บทบาทหลักในการฝึก Tabletop Exercise

ผู้เข้าร่วมแต่ละท่านจะทำหน้าที่ตามบทบาทจริงของตนเอง แต่ละบทบาทมีหน้าที่และความรับผิดชอบที่แตกต่างกันในการรับมือเหตุการณ์

🛡 CISO

ผู้บริหารสูงสุดด้านความปลอดภัยไซเบอร์

  • ตัดสินใจเชิงกลยุทธ์ด้านความปลอดภัย
  • ตัดสินใจเปิดใช้ Incident Response Plan (IRP)
  • รายงานผู้บริหารระดับสูง
  • อนุมัติงบประมาณและทรัพยากรสำหรับ IR
  • ประเมินความเสี่ยงและผลกระทบต่อองค์กร

🛠 IT Operation

ทีมเทคนิค สืบสวน วิเคราะห์ log

  • สืบสวน วิเคราะห์ log แยกแยะ IoC
  • ดำเนินการ contain / eradicate
  • เก็บ forensic evidence อย่างถูกวิธี
  • บล็อก IoC ที่ Firewall / WAF / IDS
  • ดำเนินการ Recovery จาก backup

💬 PR

ฝ่ายสื่อสารองค์กร จัดการข่าวสารภายใน/ภายนอก

  • จัดการข่าวสารภายในองค์กร
  • สื่อสารกับสื่อมวลชนภายนอก
  • เตรียมคำชี้แจงและแถลงการณ์
  • ติดตาม Social Media ที่อาจมีข่าวรั่ว
  • ห้ามเปิดเผย IoC จริงต่อสื่อมวลชน

⚖ LAW

ฝ่ายกฎหมาย ปฏิบัติตาม พ.ร.บ.ไซเบอร์, PDPA

  • แจ้ง สกมช./สคส. ตาม พ.ร.บ.กำหนดเวลา
  • ใช้แบบฟอร์ม ก.1/ก.2 สำหรับการรายงาน
  • แจ้งเจ้าของข้อมูลตาม PDPA ภายใน 72 ชม.
  • ประเมินความเสียหายทางกฎหมาย
  • รวบรวม evidence chain สำหรับการดำเนินคดี
